# ITMO Student Management

Frontend-приложение для управления студентами, разработанное на HTML, CSS и JavaScript с использованием IndexedDB в рамках лабораторной работы по веб-программированию в ИТМО.

## Возможности

- Просмотр списка студентов в таблице
- Добавление новых студентов
- Редактирование существующих студентов
- Удаление студентов
- Просмотр подробной информации о студенте
- Валидация формы с помощью HTML и JavaScript
- Хранение данных в IndexedDB
- Адаптивная верстка
- Использование семантического HTML
- Разделение интерфейса и бизнес-логики

## Данные студента

Для каждого студента хранятся:

- ФИО
- Группа
- ИСУ ID
- Номер общежития
- Номер комнаты
- Дата заселения
- Статус иностранного студента
- Заметки

## Валидация

В приложении используется встроенная HTML-валидация и дополнительная валидация на JavaScript.

Основные правила:

- Группа — одна заглавная латинская буква и четыре цифры, например `P3120`
- ИСУ ID — шестизначное число
- Номер общежития — от `1` до `99`
- Номер комнаты — от `1` до `9999`
- Дата заселения не может быть позже текущей даты
- ФИО должно содержать минимум 3 символа

## CRUD-операции

В приложении реализованы основные CRUD-операции:

- **Create** — добавление нового студента
- **Read** — получение списка студентов и просмотр подробной информации
- **Update** — редактирование данных студента
- **Delete** — удаление студента

## IndexedDB

Данные студентов хранятся локально в браузере с помощью IndexedDB.

Название базы данных:

```text
studentManagementDB
```

Название хранилища объектов:

```text
students
```

Для каждого студента автоматически создается уникальный `id`.

## Запуск проекта

Проект не требует установки дополнительных библиотек или фреймворков.

Для запуска достаточно открыть проект в WebStorm или другом редакторе и запустить `index.html` через локальный сервер.

Данные IndexedDB хранятся локально в браузере и привязаны к текущему origin.
